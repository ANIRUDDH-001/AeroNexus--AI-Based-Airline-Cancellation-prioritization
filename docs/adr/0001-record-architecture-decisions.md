# ADR-0001: Record architecture decisions

Status: accepted · Date: 2026-09-11

## Context
The Implementation Plan (§2) fixes twelve decisions that resolve conflicts between the challenge brief, the proposal and
the build constraints. Re-opening any of them silently would erode the foundation.

## Decision
Every change to a §2 decision, or any new decision with the same weight (data model shape, engine determinism,
hosting, action space), is recorded as an ADR in this folder: one file, numbered, with Context / Decision /
Consequences. The plan's decision log links to the ADR.

## Consequences
Cheap to write, easy to review, and the pitch can cite a dated record for "why did you choose X".
